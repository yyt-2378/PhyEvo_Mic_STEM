# Figure assets

Tracked figures are deliberately limited to lightweight, publication-facing summaries:

- `phyevo_mic_rsi_framework.svg`: current repository-native Chinese framework diagram (2026-10-19), including physics analysis, expert feedback, executable RSI, admission, and inherited system state; source architecture, not experimental evidence;
- `architecture.svg`: historical physics / evidence architecture diagram, retained for earlier documentation;
- `multitask_overview.png`: five-task visual overview source;
- `class1_metric_comparison.png`: final v2 Class1 metric comparison;
- `class1_multigeometry_gallery.png`: representative Class1 geometries;
- `version_iteration_overview.png`: platform iteration overview.

The original complete outputs remain under the ignored local `outputs/` tree. These copies exist only so
GitHub documentation renders without publishing raw data or multi-gigabyte prediction arrays.
