点位预算为每 512×512 像素最多 50 个候选，按图像面积缩放，匹配容差为 6 像素，点间最小距离为 4 像素；界面预算为全图 10% 面积。界面覆盖衡量专家圈定区域被覆盖的比例，不是精确界面中心线的定位正确率。未标注位置并不等于负例，因此这些标注不能直接给出完整 precision、F1 或“总体准确率”。

## 数据泄漏和选优偏倚分别判断

**在此次可核验范围内，未发现直接训练测试重叠。** 逐模型核对了训练与留出病例、采集组、源文件哈希的隔离；检查点记录的实际采样病例及来源均属于训练集；嵌入参考库仅来自训练数据；归一化图像跨组精确重复和旋转翻转重复检查没有发现重复。原生产代码哈希、模型状态、预测与输入的绑定通过核验，共记录 1,172 项输入哈希。

**但已经确认存在测试结果参与选优。** 历史报告会在外层留出评分后，比较 6 种训练策略和 3 个检查点，选择各场景较好的配置；原表还混用了两种组合分支。训练没有读取测试图，不等于测试结果没有影响最终报告的选择。此集合必须标为“事后开发最佳结果”，不能作为无偏外推性能估计。原来的严格内层选择结果另行保留，不能用本表替代。

下列限制仍然影响论文结论：

- 源文件精确去重不能排除未记录的裁剪、重采样或跨文件同源关系；没有把“未检出重复”写成“证明所有隐蔽重叠不存在”。
- 专家标注由模型辅助产生，每例不是两位专家独立盲标；接受预测的病例不能当作独立验证该预测的真值。
- 同一采集的相邻帧不是独立材料样本。三个种子的标准差只描述训练随机性，不是跨材料泛化置信区间。
- 历史开发已经参考过这些来源的表现，冻结只能防止今后版本漂移，不能倒转历史使其成为全新盲测。
- 此集合的状态来自 `rsi_cycle_002`；本次不载入或复用已隔离的不合规 dense 训练检查点。

因此，现有证据支持“真实专家监督可以补充部分场景，且 ZrO₂ 上组合优于双方的数值结果可复现”，不支持“全面超过所有模型”“已证明无任何泄漏”或“RSI 已经持续正收益”。

在项目目录使用现有虚拟环境执行只读复核：

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src:. \
MPLCONFIGDIR=/home/aiprogram/project/yaotian/next_generation_characterization/training_free_detection/.codex-tmp/matplotlib \
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
.venvs/sam2/bin/python scripts/verify_best_release_snapshot.py
```

不要对该目录再次执行 `prepare` 或 `--seal`；工具拒绝覆盖既有冻结产物。需要新实验时使用新目录，继续保留此集合。源文件改变时校验会明确失败；归档中的文件提供了已验证生产代码的副本，不要为让检查通过而修改原清单。

作者预训练权重对比应单列为“作者预训练直接迁移”，不能与“同样专家数据从头训练”混合排名。两种比较分别回答现成工具能否直接用，以及在相同监督资源下哪种方法更有效。
