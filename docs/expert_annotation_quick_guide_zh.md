# 二维 STEM 专家审核：一页操作说明

## 给专家的任务

当前界面（2026-09-17）每次显示一张可放大的原图，默认隐藏模型预测。专家需要判断：
**目标缺陷是否真实存在；如果存在，模型给出的位置、范围和类型是否正确。**

点击“显示预测轮廓”后，琥珀细线表示模型边界；青绿空心点或细线表示专家标注。页面
不会显示已有作者标签，因为进入本平台的154个病例都没有像素级标注。

## 每个病例的固定顺序

1. 先看原图，独立判断缺陷；可用“全屏看图”“原始像素 1:1”和加减按钮查看细节。
2. 按需打开“显示预测轮廓”，比较位置、范围、数量和物理类型。轮廓浓度可调淡。
3. 选择一种专家结论。
4. 接受或修正时确认“缺陷类型”；拒绝、artifact、unknown时写一句原因。
5. 点击“保存并进入下一例”。看到绿色保存提示后才算完成。

图像刺眼时调低“屏幕亮度”，也可选择“柔和深色”并全屏。两项设置只改变显示，不改原图
和坐标；浏览器会记住亮度、轮廓浓度与深浅配色。打开预测前不能提交“接受预测”或
“拒绝预测”。手机上可收起左侧审核队列，让图像占满屏幕宽度。

## 六种结论怎么选

| 结论 | 什么时候选择 | 是否进入学生模型训练 |
| --- | --- | --- |
| 接受预测 | 缺陷存在，模型位置、范围和数量基本正确 | 是，使用模型mask |
| 修正几何 | 缺陷存在，但模型多圈、漏圈、位置或范围明显错误 | 是，使用专家几何 |
| 拒绝预测 | 模型整体无物理意义，当前又无法给出可靠替代标注 | 否 |
| 无缺陷 | 图中不存在当前任务所问的目标缺陷 | 是，作为空mask正常样本 |
| Artifact | 异常主要来自漂移、失焦、扫描跳变、污染、饱和等 | 否 |
| Unknown | 证据不足或类型不能可靠判断 | 否 |

最容易混淆的是下面三种：

- 有缺陷，而且能指出正确位置：选择“修正几何”。
- 没有目标缺陷：选择“无缺陷”。
- 模型明显错误，但专家也不能可靠画出正确答案：选择“拒绝预测”或“Unknown”。

## 怎样修正几何

先把“专家结论”改成“修正几何”，同一张图就会进入“专家几何编辑”。琥珀模型边界可随时
隐藏；专家重新画出的青绿几何会完整替代模型结果。放大后选“拖动看图”移动视野，
需要继续画时再选“标注”。先保存再切换病例、通道或结论，避免遗失尚未提交的草稿。

### 原子空位、异常原子或原子柱扭曲

- 逐个轻点异常原子柱中心；
- 可以连续点击多个位点；
- 空心圈中心应落在原子柱中心，而不是落在原子间隙；
- 点错可“撤销”；删除中间某一点时选“删除单点”，再点击错点；“恢复”可找回撤销的操作。

### 错层、位错或其他线缺陷

- 从缺陷线一端开始；
- 沿缺陷中心线依次轻点控制点；
- 在弯折处适当增加控制点；
- 到另一端结束，不要沿正常原子行画多条平行线。

### 相界面、晶界或孪晶界

- 沿两侧晶格真正发生取向、周期或相组成变化的分界描线；
- 不要把整个晶粒涂满；
- 只提交一条连续界面轨迹。

### 非晶或 coherence-loss 区域

- 按住鼠标使用套索；
- 沿失去清晰周期晶格的区域外缘绕一圈；
- 松开鼠标形成闭合轮廓；
- 边缘过渡模糊时按专家认为可信的内侧边界描绘，并在备注说明不确定性。

Canvas 工具栏会实时显示点数和是否满足提交条件。绘图、撤销和清空都只修改浏览器中的未提交
草稿，不会让整个页面刷新或变暗；点击“保存当前”或“保存并进入下一例”时，完整坐标才会
和缺陷类型、备注一起提交。如果工具栏还提示点数不足，不要保存。

## 如何处理 Al Σ3 多通道病例

默认先看 HAADF。需要时切换 BF、DF2、DF4 等通道确认晶界，但不要在五个通道分别画五次。
一次结论和一条边界会关联同一物理 frame 的全部五个通道。

## 对当前截图的判断方式

旧截图中的预测把许多正常原子行分成大量水平小段。除非专家确认这些小段全部属于真实目标
缺陷，否则不能选择“接受预测”。如果专家在原图能识别出真实的不全位错或错层中心线，应：

1. 选择“修正几何”；
2. 缺陷类型选择“不全位错”或“错层”；
3. 沿真实缺陷中心线从一端到另一端点击控制点；
4. 确认出现青绿细线后保存。

具体哪条结构是真实缺陷必须由材料/STEM专家根据原图判断，平台不会把数据集说明当成空间
真值。
