## Why this appeared

规范单胞图只叠加独立 O/Si 点位时，难以看出 FAU 孔道骨架是否与实验亮柱网络一致。用户
要求增加类似分子结构的连键投影，并将同一理论骨架直接覆盖到 Y、RA、H2 图像。

## Mental model

键必须先在三维周期 CIF 中确定，再沿 `[101]` 投影。对每个 Si–O 原子对使用三维最小镜像
距离；`2.1 Å` 截止在当前 FAU.cif 中为每个 Si 恢复恰好四个 O 邻居。投影后的键若跨越
规范单胞边界，应裁成边界两侧的短线段。不能在二维投影上直接连接最近点，因为不同深度的
原子可能投影重叠，且普通欧氏线段会把周期短键画成横穿单胞的假长键。

## Prediction

对于规范横坐标 `u=0.98` 的 Si 和 `u=0.02` 的成键 O，用户预测应画成跨越左右周期边界
的短键，而不是横穿整个单胞内部的长键。

## Observation

最小镜像位移为 `+0.04`；可视化得到 `[0.98,1.00]` 与 `[0.00,0.02]` 两段，总长度保持
`0.04`。真实 FAU.cif 在 `2.1 Å` 截止下得到 768 条三维 Si–O 键，192 个 Si 全部四配位；
投影去重并裁边后得到 109 条可见线段和 78 个独立投影柱。

用户进一步发现原始 `(u,v)` 正方形显示让骨架产生斜向拉伸。检查确认 `[101]` 投影原始
基矢夹角为 `54.74°` 且长度不同，不能把两个分数轴当作等长正交轴。新增的物理矩形超胞以
`[\bar101]` 和 `[010]` 为正交方向，宽高为 `√2a=34.429 Å` 与 `a=24.345 Å`，包含四个
投影原胞和 `4 × 78 = 312` 个独立投影柱。构造这个矩形时必须包含相邻常规晶胞在
投影面上的半周期副本；仅对一个常规晶胞取模会漏掉中央竖线的 O 柱。

专家指出 Y 叠加面板的中央区域没有理论点位，用户随后用 VESTA `[101]` 投影否证了“纯孔腔”
解释。复核发现旧矩形只有 282 柱，与 4 个投影原胞应有的 312 柱矛盾。加入 `[001]`
相邻晶胞的半周期投影副本后，中央竖线恢复 6 个 O 柱。旧“超笼中心无原子”测试因而被
替换为周期中线完整性测试。严格几何中心仍不是单独原子坐标，但红圈内的周期 O 柱缺失不能解释为灰度拖尾。

## Project integration map

```text
FAU.cif 三维周期坐标
  -> 最小镜像 Si-O 距离与四配位检查
  -> [101] 投影到规范 CIF uv
  -> 周期边界裁线、投影去重
  -> 纯理论骨架 + Y/RA/H2 同骨架实验叠加页
```

## Theory and boundaries

连键是由 CIF 几何与距离截止推断的结构示意，不是 CIF 文件显式提供的键，也不是实验图像
重新识别出的化学键。二维重叠不能恢复深度顺序；相同投影端点的多条三维键会在显示中合并。
骨架叠加用于检查空间群投影、相位和晶格配准，不验证稀土元素身份。

## Alternatives

没有使用二维 Delaunay 或最近邻连线，因为它会连接投影上相近但三维不成键的原子。没有将
跨边界键直接画为一条欧氏线段，因为这会产生贯穿孔道的假连接。

## Failure modes

- CIF 化学计量、晶胞参数或占位不正确时，距离截止可能不能恢复四配位；此时函数拒绝绘图；
- 非立方或显著弛豫结构需要完整晶格矩阵，当前 FAU 投影实现不应直接外推；
- 规范单胞平均仍受局部应变和扫描漂移展宽，骨架线清晰不代表实验原子图本身已被锐化；
- 投影连键重叠会隐藏不同 z 深度，不能解释为三维键取向测量。

## User contribution

用户提出必须把 FAU.cif 分子式骨架与实验图重合，并正确预测周期边界键应显示为两侧短键。
该预测直接固化为边界自动测试。用户随后识别出分数坐标正方形造成的骨架斜向拉伸，并要求
另行保留真实 Å 比例的矩形 `[101]` 投影页；这决定了图11与图12的职责分离。
