# PhyEvo-Mic 私有项目网页工作台

本入口用于上传自己的显微图像、运行物理分析、保存判断并邀请专家。每个激活码绑定一个不可由浏览器改写的用户身份；项目默认私有。

它是独立的新服务，不替换原来的 Streamlit 专家审核，也不读取、迁移或覆盖历史专家数据库、outputs 或稿件。

当前统一入口：`python scripts/phyevo.py platform --help`。
本文末尾保留开发时的验证记录；源码发布范围和本轮验收见[发布说明](publishing_zh.md)。

## 使用步骤

1. 使用个人激活码进入网页。不要多人混用同一个码。
2. 在「我的项目」创建项目，上传二维灰度原图。支持 PNG、TIFF、JPEG；不接受彩色截图或多层 TIFF 的隐式第一层。
3. 选择原子点缺陷、相界、堆垛层错、非晶或对称关系任务，点击「开始分析」。退出网页不取消后台任务。
4. 默认查看原图，按需打开琥珀色「预测轮廓」或分数图。分数图只是本图分数的显示映射，不是正确率或校准置信度。
5. 拖动、滚轮缩放、适合窗口、1:1、全屏；按住 B 暂时隐藏所有叠加。显示使用逐图百分位对比度拉伸，分析仍使用上传灰度值，不做显示截图回流。
6. 选择结论。需要修正时使用点、线或区域工具；区域至少三个顶点后点击「完成区域」。撤销可退回未完成顶点或上一项几何。
7. 点击「保存我的判断」，看到「已持久化第 N 版」才完成。刷新后恢复自己的最新版；其他人的意见不会被覆盖。未保存修改在离开时提醒，不宣称自动保存。
8. 项目所有者可以导出完整审核 JSON，包含图像 SHA-256、任务、作者身份、版本及原图像素坐标。

预测为空不等于不存在缺陷；仍可保存专家修正。物理异常候选也不直接等同于稀土元素身份。

## 账号与明确共享

平台负责人在「账号管理」生成研究用户或专家的个人激活码，私下交给本人。激活码是可重复登录的凭据，不是一次性短信验证码；生成界面只展示一次，数据库只保存高熵凭据的摘要。

在项目内点击「邀请专家」并选择某位专家授权。专家从「专家审核」进入受邀项目：可看该项目全部图像、预测和审核历史，可以以本人身份提交意见；不能替所有者上传、启动分析或再次共享。

撤销共享后，后续资源请求立即拒绝。已经在对方浏览器显示或下载的内容不能远程收回。
收到专家意见后，可以在图像下方的「查看修正」中切换显示专家的最新几何；查看他人记录不会覆盖自己的标注，进入画图工具会回到本人修正。
管理员角色本身也不授予私人项目的网页读取权；管理员可重置他人凭据，因此仍是受信任的账户管理角色。服务器操作系统管理员属于另外的信任边界。

激活码丢失时，管理员应「重置激活码」，而不是重新创建身份。重置保持用户 ID、原项目和审核记录不变，旧码和旧会话立即失效。停用账号不会删除任何数据。

## RSI 历史进化路线

「我的项目」顶部显示历史路线回放；点击「展开进化路线」或侧栏「RSI 进化路线」可以查看完整说明并登记研究线索。动画依次呈现物理起点、专家反馈、学生协同、自主研究、能力积累、状态继承六个研发节点，以及每一阶段留下的能力。

这是对已有研发记录的定性整理，不是六个等时长的真实实验，也不是当前用户的实时任务。各阶段等长播放仅用于讲述；节点位置、连线和进度不代表性能分数、时间成本或成功率。未通过的提案不会被描述成已接纳升级，也不声称每轮都有正收益。

| 展示节点 | 仓库内对应依据 |
| --- | --- |
| 物理起点 | `README.md` 中现有物理分析框架与任务入口 |
| 专家反馈 | `docs/expert_learning_cycle_zh.md`：审核记录、监督转换与学习流程 |
| 学生协同 | `docs/rsi_framework_zh.md`：物理、学生、组合与反馈评价流程 |
| 自主研究 | `experiments/rsi_program_evolution_v1/README.md`：程序提案、隔离执行、固定评价及反馈入口 |
| 能力积累 | `experiments/rsi_program_evolution_v1/retained_portfolio.py`：保留能力组合与重放入口 |
| 状态继承 | `experiments/rsi_program_evolution_v1/composition_runtime.py`：组合执行与父状态实际调用 |

这是一条研发演进概览，不把早期人机协作节点混同为全自主实验。浏览器只加载这些不含私有数据的文字摘要，不读取历史原图、对话、预测或专家身份。

交互设计：首次进入播放一遍（约 31 秒），可暂停、重播、点击任意节点；离开页面或滚动到不可见区域自动暂停。系统启用「减少动态效果」时默认静态展示，关闭动效；仍可通过阶段按钮阅读。图像分析与专家审核工作台不嵌入此动画，以免影响看图。

下方「积累经验，再按批次进化」展示研究组织方式：留下线索 → 明确授权 → 按批次探索 → 评价后继承。一次上传或一次反馈不会立即升级框架。动画不发起训练、模型调用或研究请求；只有本人明确授权并点击登记时才保存 `requested` 记录，目前不自动消费这些记录。

## 运行方式

从仓库根目录运行，使用已有包含 `fastapi`、`uvicorn`、`Pillow` 和科学依赖的解释器。
包中声明了可选依赖组 `platform`，如需安装仅限项目隔离环境。本次未安装或升级全局包。

```bash
python scripts/serve_platform.py init
python scripts/serve_platform.py start --origin https://YOUR-HOST:8443 --port 8600
python scripts/serve_platform.py status
```

`init` 只允许空身份库执行一次，创建负责人账号并在终端展示激活码。不要把该输出写入公开日志、README 或 Git。
`start` 创建脱离终端的项目内 supervisor，同时维护 API 和 worker 进程；只绑定 `127.0.0.1`。
每个实例以文件锁禁止重复 supervisor/worker。服务状态记录于 `local_platform/v1/service.json`，`/healthz` 提供 API 和 worker 心跳状态。
服务进程退出时 supervisor 重新启动它；不会把中断分析标记为成功。排队任务继续，分析中的任务标为中断并保留原图供重试。

公网使用现有 Tailscale 用户态隧道新增的 HTTPS 8443 端口，原 443 → 8502 路由不变。
本次没有改动系统服务、开机启动、用户全局配置或旧审核 supervisor。
浏览器关闭或 SSH 退出不要求网站停止，但服务器、项目 supervisor 和 Tailscale 必须持续在线；机器重启后的自动恢复并未配置，因此不承诺固定十天无中断。
账户登录会话为 12 小时，到期重新输入个人激活码即可，项目与审核不受影响。

## 数据与资源

`local_platform/v1/platform.sqlite3` 是新平台的身份、项目、队列和审核状态库；`samples/` 保存上传原件与显示图，`jobs/` 保存轮廓、分数显示图和 JSON 摘要。它们都属于需要保留的用户数据，不是可随意清理的临时目录。

上传上限为单图 20 MiB、419 万像素、单边 4096；单用户原件 200 MiB、全站原件 1 GiB。
分析为 CPU 串行队列，单用户最多三个等待／运行任务，每次最多四分钟；不会自动训练或生成检查点。
结果池达到 512 MiB 后拒绝后续分析，最多可能超出一个正在执行的任务大小；另有限制全站累计任务数 1000。上限不触发自动删除。
本次没有大量保存预测数组或权重。

数据保存在同一服务器磁盘，不等于已有异机备份。SQLite 在线备份应使用 SQLite backup API；运行中不要仅复制主数据库而遗漏 WAL。备份或迁移到其他目录需另行明确授权。

## 权限实现

所有私有资源由服务端逐次验证会话与项目权限，而非仅隐藏侧栏。
会话采用 HttpOnly、Secure、SameSite=Strict Cookie；写操作同时检查精确 Origin 和会话 CSRF token。
错误激活码不会读取图像、项目、预测或专家记录；身份摘要库本身仍需用于认证。
不开放任意服务器路径、脚本执行、YAML 配置上传或公开静态数据目录。

登录限流不信任客户端伪造的代理 IP。激活码不出现在 URL 中；页面不使用外部 CDN、分析追踪或模型接口上传用户图像。
