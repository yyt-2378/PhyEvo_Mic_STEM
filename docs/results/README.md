# Tracked result summaries

Only compact, provenance-bearing summaries needed by the public documentation are tracked here. Full
prediction arrays, source images, and local run directories remain ignored.

- `class1_metrics.json`: final v2 post-hoc Dennler Class1 metrics;
- `class1_prediction_seal.json`: prediction manifest seal;
- `class1_score_seal.json`: score file seal.
