# PhyEvo Mic 的受控持续改进框架

PhyEvo-Mic 的目标不是让学生取代全部物理分析，而是将学习到的能力、适用范围和验证证据一起保存。
本文的 RSI 指受控的系统版本迭代：产生候选、学习已有专家修正、比较能力、决定保留或回退。
不表示系统能够自主改变科研目标，也不保证对所有未来图像无限改善。

## 当前流程

```text
原始显微图像 + 任务/参考条件
             │
      ┌──────┴────────┐
      ↓               ↓
原物理框架          专家监督学生
几何/物理量/有效区   同源像素坐标下的候选排序
      └──────┬────────┘
             ↓
      固定预算比较与协同
             ↓
    能力档案 + 原证据独立保留
             ↓
   开发研究 / 发布拒绝 / 局部准入
             ↓
     版本账本 + 显式回退
```

学习链：已有审核封存 → 正例/未知监督 → 按采集组留出训练 → 内层选择策略 → 外层评估。
本轮不需要专家重新标注。界面范围不是精确中心线，未标注部分不是确认无缺陷。
Y/RA/H2 的结构引导位点分析仍是独立任务分支，不因本轮学习而获得稀土元素真值。

## 能力对照

下表来自 `outputs/rsi_cycle_001/capability_eval_v1/` 与 `nested_analysis_v1/`。
点位预算为每 512×512 像素最多 50 个候选，匹配容差 6 px；界面预算为图像面积的 10%。
数值为三个随机种子的逐病例覆盖率平均值，单位 %。两类指标不能合成一个总体准确率。

| 来源与任务 | 原物理 | 专家学生 | 固定各半协同 | 内层选择的协同 |
|---|---:|---:|---:|---:|
| SuperScan 点位 | 0.00 | 16.09 | 8.44 | 0.00 |
| MoWTe2 点位 | 0.00 | 9.52 | 0.00 | 0.00 |
| ZrO2 界面 | 12.36 | 0.88 | 12.81 | 12.81 |
| Al Σ3 ORI 界面 | 2.77 | 3.53 | 3.13 | 2.77 |
| Al Σ3 ORII 界面 | 0.26 | 24.64 | 23.87 | 3.25 |

原物理点位的 0 只针对此次专家修正或补充的正例集合，不表示原框架的总体准确率为零。
已接受的教师预测不作为独立答案参与主比较，避免用模型自身输出证明其正确。
原物理原生输出另行报告；若超过预算，只能减少已有支持，不能给空结果补造点位。

实际观察有三点。ORII 的学生排序明显补充了专家关注的区域；ZrO2 显示原物理不能被整体替代；
固定各半在点位任务上浪费部分候选预算，协同本身不等于进步。

主比较是 151 例修正标注，来自 5 个留出采集组。SuperScan 的 99 个修正病例仍属于一个采集来源。
另有 1 例已接受预测只作审计。三个种子的离散度不是独立材料实验的置信区间。
没有穷尽负例，不能据此给出完整 precision/F1、误报率或缺陷存在概率。

## 协同规则如何避免偷看答案

除了原有 30 个外层学生对照模型，本轮使用同样的小网络、训练步数和监督方法，
在 GPU 上训练 30 个内层模型：10 个两两排除的采集组组合 × 3 个种子。
每个内层模型同时排除待评估来源和用于选择策略的内层来源。

路由只看任务几何和原物理是否有输出，不看病例号、材料标签、专家点位或待测成绩。
候选策略只有原物理、专家学生、固定预算协同。至少两个独立内层来源支持平均收益达到
1 个百分点，且每个内层来源的损失不超过 1 个百分点，才能切换；否则保留物理。
路由在读取外层指标前保存成固定文件，并与实际外层 checkpoint 绑定。

内层路由在当前五个外层来源的组均值上没有低于物理基线，但收益远小于事后挑选最好分支的想象。
点位只有两个来源：留出一个后，另一个不足以支持至少两个内层来源的条件。
“物理为空”的案例也缺少足够独立来源，路由因此保守。这是当前自动分工的能力边界，
不能通过取消检查或用测试答案选分支来隐藏。

本次仍是开发性嵌套验证。之前已研究过这些来源，重新分组不会将它们恢复成未见过的独立测试集。

## 三种不退化需要分开

1. 数据保全：原图、专家数据库、原预测和旧权重不覆盖。
2. 输出保全：原物理结果和证据独立保存，学生不会伪造物理量；可选分支异常时回退。
3. 预测性能保留：需要同预算、同任务、逐来源评估，不能用平均收益抵消某项能力损失。

前两项是工程不变量，不能冒充第三项的统计证明。版本回放比较已保存的 400、800、1,200 步
checkpoint，是同一轮优化轨迹审计，不是已经完成多轮新材料持续学习。

生产门禁另外要求独立外部证据、校准、负例与安全指标、来源级不确定性和旧能力回放。
当前部分正例开发数据不满足这些条件，因此默认物理分支仍保留。研究模式可显式启用，
不能将其开关称为生产验证通过。

## 代码职责

| 模块或入口 | 职责 |
|---|---|
| `rsi_evaluation.py` | 标签无关的同预算候选构造、逐病例和逐来源能力表 |
| `rsi_router.py` | 双重留出证据选择规则、只接收可观测条件的推理路由 |
| `rsi_policy.py` | 能力卡、证据哈希、发布门禁、追加式版本账本与回退 |
| `rsi_runtime.py` | 同源图像检测、原物理保留、可选候选输出和异常回退 |
| `scripts/evaluate_rsi_capabilities.py` | 重算现有外层预测并生成能力 CSV/JSON |
| `scripts/run_rsi_nested.py` | 可恢复的内层 GPU 学习，不增大网络 |
| `scripts/analyze_rsi_nested.py` | 冻结内层规则后评估外层、生成运行时绑定 |
| `scripts/run_rsi_detection.py` | 默认物理或显式研究模式的实际推理入口 |
| `scripts/replay_rsi_checkpoints.py` | 固定 400/800/1,200 步检查点回放，不根据外层结果改部署版本 |
| `scripts/build_rsi_release_ledger.py` | 真实开发能力卡、发布拒绝记录与追加式账本 |

上述新增模块不修改上一轮哈希冻结的学生训练器。原 `tfree-detect detect` 的默认物理流程仍可使用。
本地大结果与稿件不自动提交到 GitHub。

## 实际推理与回退

研究入口使用已绑定的外层模型，禁止把训练过全部标签的模型偷换进留出验证。
以下命令必须使用不存在的新输出目录；运行 GPU 前先确认指定设备没有其他任务：

```bash
CUDA_VISIBLE_DEVICES=2 PYTHONPATH=src:. .venvs/sam2/bin/python scripts/run_rsi_detection.py \
  --input datasets/public/guo_2021_atomic_defects/ZrO2_monoclinic_twin_boundary.tif \
  --config configs/phase_boundary.yaml \
  --binding outputs/rsi_cycle_001/nested_analysis_v1/routers/group-02-seed-23-binding.json \
  --experimental-research --student-device cuda:0 \
  --output outputs/my_new_rsi_research_detection
```

不加 `--experimental-research`，也不提交生产卡时，默认输出仍为原物理结果；
加 `--shadow` 只旁路比较、不切换主输出。恢复默认行为不需要删除模型或修改专家标注。
生产候选另须传入 `--ledger`，且能力卡必须仍处于账本的激活集合；仅提供历史 `--card`
文件不能绕过撤销或准入拒绝。推理期间若账本变化，也保留原物理结果。
病例 63、103、135 的真实 GPU 推理均已与原物理 mask 和相应留出学生分数逐位核对一致，
其中 103 走通协同主分支，另外两例按冻结规则保留物理。

12 张实际开发能力卡均未通过生产准入。账本保留其数值、哈希与拒绝理由，而不是删除失败结果。
检查点回放发现 ORII 学生的来源内 micro 覆盖率由 400 步约 40.58% 降至 1,200 步约 24.06%，
ZrO2 由约 12.77% 降至约 0.88%。这里的 micro 口径与上表 macro 口径不同。
这些回顾性观察没有被用于把运行时改成“挑出的最好检查点”。

## 怎样继续积累能力

下一轮应保留同一套能力分类、候选预算和失败原因，记录新数据的来源与用途，再生成候选版本。
可以继续使用已有标签训练，但不能把模型新预测自动当成专家真值。
新版本若只改善界面，就只提议界面能力的变更；缺证据或发生退化时保留旧策略。
反复使用的回归集应标为开发数据，新来源上的实证才能支持更广的适用范围。

本轮给出的不是“学生已经更强，所以全部升级”，而是可以被执行、复查和回退的能力积累流程。
