# PhyEvo Mic 训练改进与模型反馈实验规则

本轮要回答两个问题：学生效果不佳有多少来自训练流程，而不是模型能力本身；学生的预测和中间特征能否帮助原物理框架找到更有价值的候选。已有专家标注、原始输入、旧模型和物理检测结果均保留。新实验使用同一开发队列，因此用于比较改动与确定下一步能力边界，不称为全新外部测试。

## 为什么重新检查训练流程

原流程先等概率选任务几何，再等概率选采集来源，最后选图像。来源只有一张图时，它仍可能获得与几十帧序列相近的采样份额。在 ORII 留出的训练中，界面来源包含 ORI 和单张 ZrO₂；后者不是只占界面训练的三十一分之一。反复裁图增加了训练步数，却没有增加独立材料或独立实验的数量。

稀疏点标注也有另一个问题：随机裁块未必包含专家点。这里把“选到哪个来源”和“裁块是否含有已有标注”拆开检验，不把两种改变混称为数据增强。

专家圈出的界面宽带表示关注范围，不必等于逐像素精确界面。把整个宽带都训练成高分区，可能影响固定面积预算下的排序。本轮同时检验区域内部分高分位置的弱监督损失，以及单独加入的预测占比先验。占比先验是实验假设，不是专家提供的负标签。

## 六组逐项对照

所有组保留同一学生结构、学习率 0.001、批大小 32、128 像素裁块和三个随机种子。每个模型保存 400、800、1200 步，观察停止时机，而不是直接假定最后一步最佳。

| 配置 | 相对于上一组的变化 | 要检验的问题 |
| --- | --- | --- |
| control | 原配置重跑 | 新执行器能否复现旧基线 |
| source_sqrt | 同任务内来源采样权重改为该来源图像数的平方根 | 减少单张来源过度重复是否有益 |
| positive_crops | 一半裁块尝试覆盖训练图中的已有正标注，标注在裁块内位置随机 | 稀疏标注是否被充分用于学习 |
| photometric | 轻度强度增益、伽马、偏移和噪声扰动 | 对成像强度差异是否更稳健 |
| weak_bag | 界面宽带内只对得分最高四分之一的已标注像素施加正监督 | 宽带是否适合解释为候选范围 |
| weak_roi | 在上一组上增加预测占比惩罚 | 抑制全图高分是否改善同预算排序 |

六组是一条逐项累加的消融链，不是完整的全因子交互实验。来源图像数的平方根也不等于独立样本数；它只是与等来源采样比较的明确假设。旋转与翻转沿用原流程，新增增强不做弹性形变或尺度改变。增强保持监督坐标同步，图像内容的物理含义仍须结合真实结果检查。

## 分开评价迁移与选择

外层按五个采集来源留出，整组帧不跨训练和评价两侧。内层再排除另一来源，用于选择配置、检查点与候选组合方式。这样不能拿 ORII 自身的测试表现选择 400 步，再把该分数当作未经选择的测试成绩。

另外做两组定向实验：只用 ORI 训练测 ORII，以及只用 ORII 训练测 ORI。它们不混入 ZrO₂，也不混入点位或区域任务。这两组描述同材料不同采集条件下的迁移，与多来源多任务训练的外层结果分开报告。

共有 5 个外层折、10 个双来源排除内层折、2 个定向折，乘以 6 个配置和 3 个随机种子，为 306 次训练。不同折是不同模型，不把表格各行误解为同一模型在不同任务上的学习曲线。

主要指标仍是同预算下的已标注点召回或已标注区域覆盖：每 512×512 像素最多 50 个点，匹配容差 6 像素；区域最多占图像面积的 10%。宽带面积本身可能大于 10%，此时指标有面积预算限制。未标区域不等于无缺陷，不能由现有标注计算完整精确率、F1 或总体正确率。种子间标准差反映训练随机性，不是独立材料的置信区间。

## 模型怎样反馈物理框架

第一条路径是候选排序。保留原物理结果，给物理候选预留一部分预算；用学生分数决定这部分预算优先看哪些物理候选，再用学生的新候选补充剩余额度。与原来固定物理排序的组合使用相同预算，才能区分真正改善和单纯多圈区域。学生不改写应变、位移或其他物理测量，也不自动确认元素身份。

第二条路径是参考检索。把训练图像的编码器特征归一化，查询新图与同任务训练参考的余弦距离，返回最近的已审核案例。参考库只从训练侧按病例顺序选取，不能放入留出案例。另设一个实验性距离门控：新图距离超过训练参考彼此最近距离的第 95 百分位时，保留物理分支。参考不足两例时也不放行。相邻帧不是独立校准数据，这个阈值不是经过校准的 OOD 概率；必须报告它有无实际收益。

本轮特征是图像瓦片的编码器特征经面积加权平均后再归一化，不是每个缺陷点的独立特征。它适合观察整体成像或结构相似性；很小的局部异常可能被整图平均削弱。因此，“返回相似参考”与“判断这个点是真缺陷”是两个不同问题，当前实现只承担前者及实验性距离门控。

自动研究路由还须通过内层证据：至少两个独立采集来源、平均覆盖提升至少一个百分点、任一来源下降不超过一个百分点。否则保留物理。点位外层留出后通常只剩一个独立点位来源，因此当前队列不能单靠这些结果证明自动点位接管。可保留学生的旁路候选与参考检索，明确区分有补充价值与已能稳定接管。

## 运行时如何选择检查点

单一绑定适合观察一个学生的旁路结果。完整分析结束并封存后，`bind-family` 将同一个外层折、同一个固定种子下，内层规则选到的各个检查点绑定成一个模型组。推理时只按任务几何和物理输出是否为空查找配置；特征距离可在选定模型后触发实验性回退。不使用病例编号、材料名称或该病例的专家标注选模型，也不把不同种子的平均成绩挂在单一模型上。

```bash
PYTHONPATH=src:. .venvs/sam2/bin/python scripts/run_rsi_feedback_detection.py bind-family \
  --analysis outputs/rsi_cycle_002/analysis_v1 \
  --outer-fold outer-02 --seed 23 \
  --output outputs/rsi_cycle_002/bindings_v1/outer-02/seed-23
```

该命令要求分析已完成且校验和有效，并拒绝覆盖已有模型组。检测入口的 `--binding` 可传该目录中的 `registry.json`。这是研究复现实验的模型组，不是把五个外层模型按已知测试来源拼接成一个部署模型。对全新来源使用学生之前，仍须明确哪些训练来源和适用条件支撑该选择。

`record-evidence` 将这些模型组的真实固定种子结果接入既有能力卡与追加式记录机制。每张卡绑定检查点、内层选择、预算和外层病例指标；同时记录哪些范围继续保留物理。新记录写入新目录，旧记录不变。当前证据类别仍为开发验证，不触发生产晋升，也不将不同种子的平均值冒充某一个检查点的成绩。

## 复现检查与结果说明

`scripts/verify_rsi_refinement.py baselines` 逐项比较旧基线与原配置重跑的模型和优化器数组；`runtime` 比较原物理数组、学生分数及中间特征。同 GPU 后端要求逐值一致；CPU 与 GPU 的数值差异另行记录，不伪装成精确复现。

`experiment` 在所有注册实验结束后核对原始输入、专家冻结快照、训练与留出来源隔离、检查点和分数清单，重算内层选择及汇总，并检查真实原图运行和测试回执。这些检查证明程序与证据对应，不替代科学有效性判断。

`scripts/report_rsi_refinement.py` 生成中文 PDF、逐项训练对照图及固定病例图。纯 ORI→ORII 与多来源训练分开列出；事后最佳与内层选择后的结果分开列出；内层检查未能避免的外层退化也必须保留在报告中。

结果还要结合输出形态解释：原图最暗区域的高分占比是无标签行为诊断，不是误报率；界面宽带的面积预算上界是评价限制，不是归一化后的新准确率。覆盖增加但候选更分散时，不能声称界面细线定位已经更精确。

## 方法参考

区域约束可用于弱监督，但本项目的部分专家关注区域不满足“区域外都是背景”的假设，因此没有照搬区域外负监督。参见 [Kervadec 等的弱监督分割原论文](https://proceedings.mlr.press/v121/kervadec20a.html)。

深层特征近邻距离可用于研究分布偏移。此处仅借鉴检索思路；当前编码器没有经过该论文的完整 OOD 验证，不能直接继承其结论。参见 [Sun 等的深度近邻 OOD 原论文](https://proceedings.mlr.press/v162/sun22d.html)。
